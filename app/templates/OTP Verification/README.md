# [DROP #004]

A sleek, interactive Secure Vault Access code verification component featuring fluid orbital animations, responsive OTP inputs, loading state morphs, and celebratory success explosions.

## Preview

Open `index.html` in your browser.

## Installation

1. Download the ZIP.
2. Extract the folder.
3. Open the folder in VS Code.
4. Open `index.html` in your browser.

## Files

- `index.html` — HTML structure & vault stage
- `style.css` — Animations, layout, and glassmorphic styling
- `script.js` — Input state management, verification logic, and celebratory confetti
- `assets/` — Local assets directory
